# SmartTrade Portfolio

A Java-based personal investment simulator designed to demonstrate stock trading, portfolio management, and market analysis.

## Project Overview

SmartTrade Portfolio is an educational stock market simulation application developed using Java. It allows users to monitor stocks, perform buy and sell transactions, manage their portfolio, and analyze profit or loss.

## Features

- Stock market monitoring
- Buy and sell stock transactions
- Portfolio management
- Real-time simulated market updates
- Profit and loss calculation
- Risk-level analysis
- Trade activity tracking
- CSV-based portfolio data management
- Portfolio report generation

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- File Handling
- CSV Data Processing
- Java Swing GUI
